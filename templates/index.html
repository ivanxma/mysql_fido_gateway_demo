02 · User enrollment

Register your YubiKey

Use your MySQL username and password. Insert your key into your computer, then register it.

Requires a FIDO2 key with discoverable credentials, PIN/user verification, and packed ES256 attestation. Browser prompts stay local; the PIN is never sent to Python.
03 · Database login

Login · Hello world

MySQL checks your password and the signed response from your registered key.


Success requires MySQL authentication OK and SELECT 'hello world' on that user’s connection. No shared database account or app-only FIDO fallback.


Each operation uses its own MySQL connection. No server-attached YubiKey, terminal prompts, or mysql CLI client is used.
