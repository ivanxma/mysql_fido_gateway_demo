# Versioned public downloads

`0.3.0/` contains the project wheel, full frontend starter ZIP, and SHA-256
checksums. These files are generated by `python scripts/build_release.py`.
They contain MIT-licensed project code/templates, the personal-project
disclaimer, and separate third-party license notices. Dependency binaries
such as MySQL Connector/Python are installed by pip, not bundled here.

The getting-started guide uses raw.githubusercontent.com URLs under this
path. Download links become reachable after these files are pushed and the
repository is made public. The build script prepares the files locally; it
neither publishes a GitHub release nor changes repository visibility.
